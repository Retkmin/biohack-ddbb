1. VISIÓN GENERAL DEL MÓDULO
El módulo de Gestión de Recetas permite al usuario crear un recetario personalizado, planificar su semana alimenticia con tolerancia de macros, y generar listas de compra automáticas optimizadas. El sistema asegura adherencia mediante flexibilidad semanal en lugar de rigidez diaria.
1.1 Filosofía de Flexibilidad Semanal
CRÍTICO: El sistema evalúa cumplimiento de macros en ventanas de 7 días, NO día a día. Esto permite flexibilidad sin perder rigor científico.
Ejemplo:
Objetivo semanal proteína (Fase A.1, LBM 71.3 kg): 164g/día × 7 = 1,148g/semana
Lunes: 150g (−14g) → ⚠️ Alerta diaria, pero sin bloqueo
Martes: 178g (+14g) → Compensa el déficit del lunes
Balance semanal al final del martes: 328g (objetivo 328g) → ✅ Cumplido
1.2 Tolerancias del Sistema
Ejemplo de tolerancia semanal en acción:
SEMANA TIPO (Fase A.1):

Objetivo semanal: 1,148g proteína | 455g grasa | 840g HC

Días 1-4 (déficit): 160g prot/día = 640g acumulado
Día 5 (recarga social): 200g prot = 840g acumulado
Días 6-7 (déficit): 155g prot/día = 1,150g acumulado

RESULTADO: 1,150g vs objetivo 1,148g (+0.17%) → ✅ PERFECTO

2. GESTIÓN DE RECETAS
2.1 Estructura de una Receta
Cada receta contiene:
Metadatos: Nombre, categoría (desayuno/comida/cena), tiempo de preparación
Ingredientes: Lista con cantidades base (para 1 ración)
Macros totales: Proteína, grasa, HC, calorías (calculados automáticamente)
Instrucciones: Pasos de preparación (opcional, para referencia del usuario)
Etiquetas: Tags personalizables (ej: 'rápida', 'batch-cooking', 'sin lactosa')

2.2 Creación de Recetas Asistida por IA
El usuario puede crear recetas de 3 formas:
1. Manual: Formulario tradicional con campos de ingredientes y cantidades
2. Por Texto (IA): Usuario describe la receta en lenguaje natural
Ejemplo: "Ensalada de atún con 150g de atún en lata, 100g de lechuga, 50g de tomate cherry, 30g de maíz dulce, aliñada con aceite de oliva y vinagre"
→ Sistema extrae ingredientes, calcula macros automáticamente y crea la receta
3. Por Imagen (IA): Usuario sube foto del plato terminado
→ Sistema identifica ingredientes visualmente, estima cantidades y pide confirmación antes de crear la receta
2.3 Escalado Dinámico de Raciones
El sistema puede ajustar las cantidades de cualquier receta para cumplir objetivos específicos de macros.
Caso de uso: Planificación de cena con déficit proteico
SITUACIÓN:
- Macros actuales del día: 110g proteína, 58g grasa, 100g HC
- Objetivo del día: 165g proteína, 65g grasa, 120g HC
- Déficit para cena: 55g proteína, 7g grasa, 20g HC

RECETA BASE: Pollo con arroz (50g prot, 7g grasa, 39g HC)

ESCALADO DEL SISTEMA:
- Proteína: 55g objetivo / 50g base = factor 1.1
- Grasas: 7g objetivo = 7g base → factor 1.0 (perfecto)
- HC: 20g objetivo / 39g base = factor 0.51

RECETA AJUSTADA:
- Pechuga de pollo: 220g (era 200g) → 51g prot
- Arroz basmati: 75g (era 150g) → 20g HC
- Aceite: 5ml (igual) → 5g grasa

RESULTADO: 53g prot, 7g grasa, 20g HC → ✅ Cumple déficit

3. PLANIFICACIÓN SEMANAL INTELIGENTE
3.1 Algoritmo de Planificación
El sistema genera un plan semanal siguiendo este proceso:
Análisis del Perfil: Lee fase activa (Déficit A, B, Mantenimiento), suelos biológicos, y preferencias del usuario
Identificación de Días Especiales: Detecta días de recarga (2/semana en déficit) y eventos sociales marcados por el usuario
Selección de Recetas: Elige del recetario personal aplicando restricciones de variedad (máx 2 repeticiones/semana)
Escalado por Día: Ajusta cantidades de cada receta para cumplir objetivos diarios respetando tolerancias
Validación Semanal: Verifica que los macros acumulados de 7 días estén dentro de tolerancia (±5%)
Optimización: Si no cumple, reintenta con diferentes combinaciones hasta encontrar plan válido (máx 50 iteraciones)
3.2 Restricciones y Reglas de Asignación
3.3 Auditoría de Recetario Insuficiente
Antes de generar el plan, el sistema valida que el recetario del usuario contiene suficientes recetas compatibles.
Ejemplo de alerta de auditoría:
⚠️ RECETARIO INSUFICIENTE

No es posible generar un plan semanal que cumpla tus suelos biológicos con las recetas actuales.

PROBLEMA DETECTADO:
Solo tienes 3 recetas de cena con suficiente proteína (>40g). Necesitas al menos 5 para cumplir variedad.

SUGERENCIAS:
• Añade 2 recetas más de cena con pescado o carne magra
• Ejemplos: Merluza al horno (50g prot), Ternera con verduras (48g prot), Atún con quinoa (45g prot)

[Ir a Recetas Sugeridas] [Crear Receta Nueva]
3.4 Flexibilidad Inteligente
El sistema NO genera un plan rígido, sino un plan adaptable:
Swap de Recetas: Usuario puede intercambiar cualquier comida del plan por otra receta compatible (mismo slot, macros similares)
Replanificación Parcial: Si el usuario no cumple un día, el sistema ajusta automáticamente los 6 días restantes
Eventos No Planificados: Si hay una comida social inesperada, el sistema reasigna macros del resto de la semana
Ejemplo de replanificación automática:
SITUACIÓN:
- Miércoles: Usuario registró solo 140g proteína (objetivo era 165g)
- Déficit acumulado: −25g proteína
- Días restantes: Jueves a Domingo (4 días)

ACCIÓN DEL SISTEMA:
- Recalcula objetivo para los 4 días restantes
- Nuevo objetivo diario: 165g + (25g ÷ 4 días) = 171g/día
- Ajusta las recetas del plan: Jueves a Domingo ahora con +6g prot/día

NOTIFICACIÓN AL USUARIO:
"Tu plan del resto de la semana se ha ajustado automáticamente para compensar el déficit de ayer. Objetivo actualizado: 171g proteína/día (era 165g)."

4. GENERACIÓN DE LISTA DE COMPRA
4.1 Proceso de Generación
Extracción de Ingredientes: Sistema recopila todos los ingredientes de las recetas del plan semanal
Agregación Inteligente: Suma cantidades del mismo ingrediente que aparece en múltiples recetas
Conversión de Unidades: Normaliza unidades (ej: 500g → 0.5kg, 1500ml → 1.5L) para facilitar compra
Categorización: Agrupa por secciones del supermercado (Proteínas, Verduras, Lácteos, Despensa, etc.)
Redondeo Comercial: Ajusta a formatos de venta real (ej: 230g pechuga → 250g paquete estándar)
Generación Final: Crea lista exportable (PDF, texto, o integración con apps de supermercado)

4.3 Optimizaciones Inteligentes
Batch Cooking: Si 3+ recetas usan el mismo ingrediente, sugiere cocinar cantidad completa de una vez
Desperdicio Mínimo: Ajusta cantidades a formatos comerciales (ej: si necesitas 230g y se vende en paquetes de 250g, añade 20g a otra receta)
Sustituciones: Sugiere alternativas si un ingrediente es estacional o caro (ej: brócoli → coliflor si es temporada)
Integración con Supermercados: (Futuro) Exporta lista directamente a apps como Carrefour, Mercadona, etc.

5. AUDITORÍA SEMANAL DE MACROS
5.1 Métricas de Seguimiento Semanal
Cada domingo, el sistema genera un reporte de adherencia al plan:
5.2 Ejemplo de Reporte Semanal
📊 REPORTE SEMANAL: 14-20 Abril 2026

ADHERENCIA A MACROS:
✅ Proteína: 1,165g / 1,148g objetivo (101.5%) → EXCELENTE
✅ Grasas: 468g / 455g objetivo (102.9%) → EXCELENTE
⚠️ Carbohidratos: 792g / 840g objetivo (94.3%) → ACEPTABLE

DÉFICIT ACUMULADO:
• Objetivo semanal: 4,200-5,250 kcal
• Déficit real: 4,680 kcal
✅ Dentro del rango óptimo

VARIABILIDAD:
• Proteína: σ = 12g (baja variabilidad ✅)
• Grasas: σ = 8g (muy estable ✅)
• HC: σ = 22g (moderada variabilidad ⚠️)

DÍAS FUERA DE TOLERANCIA:
• Miércoles: HC 95g (−21% objetivo) → Compensado jueves
• Resto de días: Todos dentro de tolerancia ✅

RECOMENDACIONES PARA LA PRÓXIMA SEMANA:
1. Aumentar HC ligeramente en días de déficit (+10g/día)
2. Mantener estrategia actual de proteínas (excelente adherencia)
3. Considerar añadir 1 receta más con batata/arroz al recetario
5.3 Ajustes Automáticos del Sistema
Basándose en el reporte semanal, el sistema puede:
Ajustar Objetivos Automáticamente: Si adherencia es consistentemente 95-98%, reduce objetivos ligeramente (más sostenible)
Sugerir Nuevas Recetas: Si un macro está consistentemente bajo, recomienda recetas del repositorio público que lo mejoren
Modificar Días de Recarga: Si déficit acumulado es >6,000 kcal/semana, añade un día de recarga extra
Alertar Break Necesario: Si adherencia cae <80% durante 2 semanas consecutivas, sugiere semana de mantenimiento

Integración con módulo IA para creación por texto/imagen
